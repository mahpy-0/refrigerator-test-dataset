both of DeviceState and iot_middleware_data have these parameters:

1. message: this parameter is the text that either the user said and speech to text system recognized it ( in DeviceState ) or its the llm response ( in iot_middleware_data ). this text has gaurdrails that prevent from answering not related questions. it doesn't have range, it get checked using semantic methods.

2. refTemp: this parameter is number indicating temperature of the refrigerator. this parameter is in range of 1 as coldest and 7 as warmest.

3. frzTemp: this parameter is number indicating temperature of the freezer. it ranges from -16 as warmest and -24 and coldest.

4. iceType: this parameter is string that shows what type of ice will gets out. there is two type "Crushed" or "Cubed".

5. smartMode: this is string parameter which will tell the system how the compressor performance, fans speed, energy consumptin should be. possible types are "Default", "Power Saving", "Guest", "Night", "Novelty", "Off".

6. supperRef: this parameter is boolean that shows if the mechanism of fast cooling the refrigerator is on or off. has two type "true" for on and "false" for off. also known as super cool.

7. supperFrz: this parameter is boolean that shows if the mechanism of fast cooling the freezer is on or off. has two type "true" for on and "false" for off. also known as freeze

8. magicZone: this parameter is boolean that shows if the basket for keeping meat and other stuff that needs 0 temperature is on to cool thing or off. has two type "true" for on and "false" for off. also known as chiller zone, freshness box.

9. iceMaker: this parameter is boolean that show the ice maker mechanism is on or off. has two type "true" for on and "false" for off.

10. light: this parameter is boolean that shows if the lights of water cooling part at front door is on or off. has two type "true" for on and "false" for off. also known as lighting.

11. childLock: this parameter is boolean which shows if child lock safety is on or off. has two type "true" for on and "false" for off.

12. sleepMode: this parameter is boolean that shows if the mechanism for lowering refrigerator noises and sound in night time is on or off. has two type "true" for on and "false" for off.

13. vacation: this parameter is boolean that shows if mechanism for eco mode is on or off. has two type "true" for on and "false" for off. also known as eco mode, holiday.

14. Hygiene: this parameter is boolean that shows if the air filter is on or off. has two type "true" for on and "false" for off. aslo known as air filter, hygen, plasma function, air purifier.

15. doorAlarm: this parameter is boolean that show if mechanism for alarming user when they left refrigerator or freeze door open is on off. has two type "true" for on and "false" for off. also known as alarm.

16. extraRef: this parameter is boolean that show if the mechanism in some double or combi refrigerator that gives boosting cooling is on or off. has two type "true" for on and "false" for off.

17. filterReset: this parameter is boolean which rests water filter counter that tracks hours of water filter time after change. if "true" it means there is request for reset if "false" there is no request for reset so no change in system.

18. water: this parameter is boolean that shows if the water dispenser is active or deactive. has two type "true" for activate and "false" for deactive.

19. iceFull: this parameter is boolean that shows if the ice basket is full or not. has two type "true" for full and "false" for empty or not full. this parameter is read only ( can't request fot set ).

20. filterTime: this parameter is integer number ( 0 =< x ) which indicates hours after changing of water filter. this parameter is read only ( can't request fot set ).

21. environmentTemp: this Parameter is normal number ( noraml room temperature ) that is showing temperature of around the refrigerator. this parameter is read only ( can't request fot set ).

22. ragImageURL: this parameter is string that has the link to an image or to a page for help. this Parameter is rag system output and always set to Null for this dataset.

in the iceType and smartMode there was different types of possible value, here is explanation of them:

a. iceType:

1. Crushed: this is function for makeing crushed ice using blades right before ice drops from ice dispence, which is better for faster cooling, and in situation where faster cooling is needed. also known as crushed, powdered ice, small ice, crush.

2. cubed: this is how normal ice are made and dispencer drops them, better for fancy drinks, more lasting. also known as cube, dice, dice ice, normal ice.

b. smartMode:

1. Novelty: inovation mode. this mode activate a higher level of user experience. by analyzing user daily routin, activates a optimized algorith setting spesific to this user. this mode is for when user asks for modern, intelligent for their refrigerator.

2. Power Saving: this mode changes compressor performance and lowers device power consumption while maintain same temperature to lessen power consumptin.

3. Guest: this mode is for party times when refrigerators door, open often and cold temperature get wasted. this mode activate cooling system with higher power to make up for lost cold temperature. this mode is also usefull for times that user is filling the refrigerator after shopping.

4. Night: this mode slows fan speed and control compressor rpm to make it quiet in night time.

5. Default: this mode uses factory default settings. this mode is balance between keeping food fresh and normal power consumptin. user usually switch to this mode when they want to exit temporary modes and just work normal.

6. Off: this one is for switching off from any smart mode and reseting to manual setting.
